红警2原版单机修改器

适用范围：Steam《红色警戒2》原版单机。
不支持联机、局域网、MOD、尤里的复仇或其他版本。

快速开始：
1. 启动 Steam 红警2原版，并进入单人任务或遭遇战。
2. 运行 ra2_product_ui.exe。
3. 等待顶部显示“游戏进程：运行中 · V1.006”。
4. 点击需要的功能行即可启用；再次点击即可关闭。

修改器会自动监视游戏连接状态。游戏未启动或尚未进入任务时，相关开关会自动禁用。
启动时会执行组件自检和游戏版本校验；所有修改仅作用于当前游戏会话。
底部“查看日志”可查看、复制或导出本次会话的诊断日志；日志不包含 Steam 登录信息或联机数据。

安全说明：
- 不修改磁盘上的 game.exe、存档或 rules.ini。
- 不支持联机、局域网或任何需要公平性的游戏模式。
- 如果版本不匹配，修改器会拒绝写入。
- 退出游戏后，驻留型维修功能会自动退出。

运行环境：Windows x86/x64，界面需要系统 .NET Framework 4.x；C 组件不需要额外 VC++ 运行库 DLL。

发布目录只包含产品组件，不包含研究探针、调试器或一次性实验工具。
